# Historical boundaries

Simplified copies (tolerance ~0.01°) of `world_1914.geojson` and `world_1938.geojson` from
**historical-basemaps** by André Ourednik — https://github.com/aourednik/historical-basemaps —
licensed under the **GNU General Public License v3.0**.

Only the properties NAME, SUBJECTO, PARTOF and BORDERPRECISION are kept. Borders are approximate
(BORDERPRECISION: 1 approximate, 2 moderate, 3 defined by international law) and the dataset
contains known anachronisms; see docs/DATA_POLICY.md. Regenerate with `python scripts/prepare_geodata.py`.
